<original_problem_statement>
The user wants to build a Grand Theft Auto (GTA) style GPS RPG game.

**PRODUCT REQUIREMENTS:**
- **Core Gameplay:** Monster battles and missions triggered by GPS location.
- **Map & Theme:** A real-world map (using OpenStreetMap) that shows the player's location, enemies, missions, and dynamic shops.
- **GPS Movement:** The player's character on the map must move in real-time as the player moves in the real world.
- **Character System:** A character screen showing stats, skills, inventory, and equipable items. Players should be able to upload a custom profile picture.
- **Authentication:** Players must be able to create an account (login/password) to save their character, inventory, and game progress.
- **Economy:** An item shop, item drops from battles, and dynamic, location-based gun shops on the map.
- **Multiplayer:** PvP, Guilds, Leaderboards, and Territory control.
</original_problem_statement>

**User's preferred language**: English

**what currently exists?**
A feature-rich full-stack application with a FastAPI backend and an Expo (React Native) frontend. The game is highly functional.
- **Backend ():** A comprehensive API server managing users, players, items, shops, battles, and a full territory control system. It connects to a MongoDB database and includes logic for temporary buffs, daily income from territories, and game balance calculations.
- **Frontend (Expo):** A multi-tab application.
    - **Authentication:** Full login/signup flow with session persistence. A bug with non-functional text inputs on the login screen has been fixed.
    - **Map:** A real-time map ( with OpenStreetMap) showing the player's live position. The player's marker now uses their profile picture. The map also displays enemies, missions, dynamic shops, and interactive territory circles.
    - **Character:** A detailed character screen. The profile picture upload feature has been significantly improved with image resizing/compression to handle large files from phone cameras, and the updated picture now instantly syncs to the map icon via a global Zustand store.
    - **Shop:** A dedicated Shop tab for purchasing consumables (health/energy recharges) and temporary stat boosts (e.g., +Max HP for 5 battles).
    - **Territories:** A fully implemented territory control system. Players can see colored, non-overlapping territory circles on the map, click them to view details (owner, daily cash income, boss stats) in a modal, and fight a boss to capture the territory.
    - **Re-balancing:** Shop prices and monster difficulty have been increased twice based on user feedback.
