# RCA — Deploy run 9a94fca6-e47b-44f4-8a54-7383c8920d09 (gta-quest-map)

## Verdict
**Source-code bug.** The deploy failed at `build_image` in the **EAS OTA / Metro bundling** lane (`eas update`). It is NOT an infra, manifest, secret, or platform problem. The backend Docker image is unaffected; this is a JavaScript/TSX syntax error in the frontend bundle.

## Failing step
`build_image` → EAS lane `eas update` → Metro/expo-cli bundling.

## Exact error (from Cloud Build)
```
[expo-cli] ERROR  SyntaxError: /workspace/frontend/app/(tabs)/index.tsx: Expected corresponding JSX closing tag for <ScrollView>. (4795:10)
Error: update command failed.
```
(The preceding `git rev-parse --show-toplevel exited with non-zero code: 128` / `Falling back to using current working directory` lines are benign EAS-cli noise, not the cause.)

## Root cause
In `frontend/app/(tabs)/index.tsx`, inside the park modal's "PLAYABLE ACTIVITIES" panel:
- line 4712 opens the panel wrapper `<View style={{ padding: 12, paddingBottom: 4 }}>`
- line 4715 opens `<ScrollView style={{ maxHeight: 320 }} showsVerticalScrollIndicator={true} nestedScrollEnabled={true}>`
- the activity rows + the "coming soon" `<View>` (closed at line 4794) are its children
- line 4795 has `</View>` (closing the panel wrapper) **but the `<ScrollView>` opened at 4715 was never closed**.

The parser reaches the panel's `</View>` while `<ScrollView>` is still open, hence "Expected corresponding JSX closing tag for <ScrollView>. (4795:10)".

## Fix (one line)
Insert a `</ScrollView>` between the current line 4794 and 4795 — i.e. close the ScrollView after the "coming soon" `</View>` and before the panel's `</View>`:

```tsx
              <Text style={{ backgroundColor: '#555', color: '#ddd', ... }}>SOON</Text>
            </View>
            </ScrollView>   <-- ADD THIS LINE (closes <ScrollView> opened at line 4715)
          </View>
          <TouchableOpacity
            style={{ margin: 16, marginTop: 8, backgroundColor: '#E91E63', ... }}
```
