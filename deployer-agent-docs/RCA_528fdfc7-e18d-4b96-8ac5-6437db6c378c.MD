# RCA — Deploy run 528fdfc7-e18d-4b96-8ac5-6437db6c378c (gta-quest-map)

## Outcome
FAILED at `build_image`, in the **EAS OTA update (Metro bundling)** lane. Backend docker image was unaffected; the Metro export crashed, failing the whole Cloud Build. The old run (8e2c457d…) is still live — nothing was promoted.

## Root cause (reproduced in eph sandbox)
`frontend/app/(tabs)/index.tsx` imports a module that does not exist in the source:

```
line 83: import { FOOTBALL_HTML } from '../../components/FootballHtml';
```

Metro error from the build log:
```
[expo-cli] Unable to resolve "../../components/FootballHtml" from "app/(tabs)/index.tsx"
None of these files exist:
  * components/FootballHtml(.ts|.tsx|.js|.json|...)
  * components/FootballHtml
```

Verified in the eph pod against the pulled source:
- `frontend/components/` contains `BasketballHtml.ts`, `TexasHoldemHtml.ts`, `PoolGameHtml.ts`, etc. — but **no `FootballHtml.ts` (or any extension)**.
- `FootballHtml` is referenced in exactly one place: the import on line 83.
- `FOOTBALL_HTML` is actually consumed at line 2323: `source={{ html: FOOTBALL_HTML }}` (a WebView), mirroring `BASKETBALL_HTML` at line 2294.

So the symbol is both imported and used, but the backing file was never added to the repo.

## Fix (Source — E1 to apply in the preview environment)
Two options:

1. **Add the missing file** `frontend/components/FootballHtml.ts` exporting `FOOTBALL_HTML`, following the exact shape of the sibling `components/BasketballHtml.ts`:
   ```ts
   export const FOOTBALL_HTML = `<!DOCTYPE html> ... </html>`;
   ```
   This preserves the football WebView rendered at line 2323.

2. **Remove the feature** if football isn't intended to ship: delete the import on line 83 **and** the usage block around line 2323 that references `FOOTBALL_HTML`.

Option 1 is preferred since the component is wired into the UI. After applying, re-trigger the deploy.

## Notes
- This is app source, not a deployment manifest — no manifest change applies.
- Re-running the pipeline on unchanged source will reproduce this exact Metro failure.
