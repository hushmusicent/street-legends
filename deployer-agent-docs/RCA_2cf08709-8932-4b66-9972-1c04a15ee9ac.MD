## Summary
The deploy failed at `build_image`, in the **EAS OTA update lane** (Metro/Babel bundling during `eas update`). This is an **app-source** fault — a JSX syntax error — not an infra or manifest problem. It reproduced identically across the last 3 redeploy runs (2cf08709, 3d5efc9f, 9a94fca6).

## Exact error
```
[expo-cli] ERROR  SyntaxError: /workspace/frontend/app/(tabs)/index.tsx:
Expected corresponding JSX closing tag for <ScrollView>. (4795:10)
```
(The `git rev-parse --show-toplevel ... exited with non-zero code: 128` lines above it are benign EAS-CLI noise — the real failure is the SyntaxError.)

## Root cause
In `frontend/app/(tabs)/index.tsx`, the `PARK_SCROLL_PANEL` `<ScrollView style={{ maxHeight: 320 }} showsVerticalScrollIndicator={true} nestedScrollEnabled={true}>` opened at **line 4715** is never closed. The activity-card `<View>`s inside it close normally (last one at line 4794), and then line 4795 closes the panel wrapper `<View>` that was opened at line 4712 — but the `</ScrollView>` for the tag opened at 4715 was skipped. The parser hits the panel's `</View>` at 4795 where it expected `</ScrollView>`, hence the error at `(4795:10)`.

Tag census before fix (ScrollView open/close in file): 4564→4610 ok, 4628→4669 ok, 4702→4711 ok, **4715→(none)**, 5446→5485 ok, 5515→5539 ok, 5611→5620 ok. The 4715 opener had no matching closer.

## Fix (verified)
Insert a `</ScrollView>` between the last activity card's `</View>` (line 4794) and the panel's `</View>` (line 4795), at the same 12-space indent as the cards:

```tsx
              <Text style={{ backgroundColor: '#555', color: '#ddd', fontWeight: 'bold', fontSize: 12, paddingVertical: 6, paddingHorizontal: 10, borderRadius: 20 }}>SOON</Text>
            </View>
            </ScrollView>      {/* <-- ADD THIS: closes the PARK_SCROLL_PANEL ScrollView opened at line 4715 */}
          </View>
          <TouchableOpacity
```
