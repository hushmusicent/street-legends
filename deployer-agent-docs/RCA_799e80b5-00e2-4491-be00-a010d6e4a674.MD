(The `git rev-parse --show-toplevel ... code: 128` lines above it are benign EAS warnings, not the cause.)

## Root cause — user source, JSX syntax error
File: `frontend/app/(tabs)/shop.tsx`, line **409**.

The render uses a nested ternary over `filter`:
```
405:  {filter === 'bonus' ? (
406-408:    <ScrollView> ... <BonusBundles .../> ... </ScrollView>
409:  ) : {filter === 'house' ? (      <-- STRAY `{`
...
501:  ) : (
...
```
Line 409 has a stray opening brace `{` before `filter === 'house'`. Inside a JSX expression this is parsed as the start of an object literal, so Babel/Metro fails with `Unexpected token, expected "," (409:18)`. The `else` branch of a JSX ternary must be a bare expression, not wrapped in `{ }`.

## Fix (exact, one line)
In `frontend/app/(tabs)/shop.tsx` line 409, remove the stray `{`:
```
-      ) : {filter === 'house' ? (
+      ) : filter === 'house' ? (
```
No other change is needed — the chain already closes correctly (`) : (` at 501, final `)}` later). Only the single `{` was extra.
