# RCA — redeploy run 3d5efc9f-9b21-4890-a40e-0d4f80e43f05 (gta-quest-map)

## Outcome
Deploy FAILED at `build_image`, EAS OTA lane (`eas update` Metro/expo-cli bundling). Backend Docker lane is irrelevant — this is a frontend JS syntax error. The previous healthy run (7882d314) is still live; nothing was promoted.

## Error (verbatim from Cloud Build)
```
[expo-cli] ERROR  SyntaxError: /workspace/frontend/app/(tabs)/index.tsx: Expected corresponding JSX closing tag for <ScrollView>. (4795:10)
    Error: update command failed.
```
(Two identical failures: runs 9a94fca6 and 3d5efc9f — same cause.)

## Root cause
`frontend/app/(tabs)/index.tsx` has an **unclosed `<ScrollView>`**.

- Line **4715** opens the "PARK_SCROLL_PANEL": `<ScrollView style={{ maxHeight: 320 }} showsVerticalScrollIndicator={true} nestedScrollEnabled={true}>`.
- It contains the activity list (`<TouchableOpacity>` items for Basketball/Football/Baseball/Soccer/Tennis/1-on-1 and the "coming soon" `<View>`).
- That `<ScrollView>` is **never closed**. The `</View>` at line 4795 (10-space indent) closes the panel `<View>` opened at line 4712, which leaves the ScrollView dangling. Babel/Metro therefore reports "Expected corresponding JSX closing tag for `<ScrollView>` (4795:10)".

## Fix (verified in eph sandbox)
Insert one `</ScrollView>` between line 4794 and line 4795 — i.e. after the coming-soon block's closing `</View>` (4794) and before the panel-closing `</View>` (4795):

```
...
              <Text style={{ backgroundColor: '#555', ... }}>SOON</Text>
            </View>            <-- line 4794 (closes "coming soon" View)
            </ScrollView>      <-- INSERT THIS (closes <ScrollView> opened at 4715)
          </View>              <-- line 4795 (closes panel <View> opened at 4712)
...
```
