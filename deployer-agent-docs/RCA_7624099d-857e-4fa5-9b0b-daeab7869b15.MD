## Root cause — SOURCE (frontend)
A JSX syntax error in `frontend/app/(tabs)/shop.tsx` at **line 409, column 18**.

Build log:
```
[expo-cli] ERROR  SyntaxError: /workspace/frontend/app/(tabs)/shop.tsx: Unexpected token, expected "," (409:18)
```

The code is a nested ternary rendered inside a single JSX expression `{ ... }` (opened at line 405, closed by `)}` at line 576). Line 409 inserts a **stray `{`** after the `:` of the outer ternary:

```tsx
405:       {filter === 'bonus' ? (
406:         <ScrollView ...>
407:           <BonusBundles playerId={playerId} />
408:         </ScrollView>
409:       ) : {filter === 'house' ? (     <-- stray `{` at col 18
```

Because line 405's `{` already put the parser in JS-expression context, the `{` at 409 starts an object literal, and `filter === 'house'` inside an object literal is invalid → `Unexpected token, expected ","`.

## The fix (one character)
Remove the stray `{` on line 409:

```tsx
-      ) : {filter === 'house' ? (
+      ) : filter === 'house' ? (
```

This turns it into a valid nested ternary `{ cond1 ? (...) : cond2 ? (...) : (...) }`, and the braces balance correctly with the existing `)}` at line 576 — no other edit (no extra `}` removal) is needed.
